## v2.0.0-beta.3 测试版

本版适用于 Windows x64。实验性主线自动推进仅支持安卓模拟器（ADB）。国服 PC 客户端可继续使用前台或两种后台模式运行手动双城跑商。

### 双城跑商（#6）

- 在交易所点击「我要买」或「我要卖」后，若仍停在原菜单，会原地重试一次。
- 修复载货量斜杠被识别成数字 1 后的选货误判。选货、买入前复核和买入后复核会沿用已确认的仓容。点击后读数冲突会重新读屏，仍无法确认时停止本次买入。
- 自动选线和手动双城的利润估算、采购顺序使用国服实时行情。首次使用需联网获取报价，之后接口暂时不可用时可沿用最近一次成功获取的行情。

### 模拟器日常任务（#8）

- 新增一键日常队列，可组合商店采购、活动刷关、众志攻坚等任务。商店付款前会核对数量、阶梯总价和各币种保留额。
- 体力恢复按任务配额执行，桦石每轮最多 8 次。活动入口打不开或后续页面长期无法识别时，会尝试返回大厅。

### 模拟器主线自动推进（#9，实验性）

- 可识别城内主线标记，导航到任务车站，并衔接剧情、编队和战斗。识别到战败后停止。制作类任务和部分非城市对话仍需手动处理。
- 发车前先定位本轮主线站，按完整里程判断是否到站。出发确认框延迟出现时会等待，持续无法确认时会停止并提示。
- 「仅补空位」会保留剧情角色和手动上阵成员。「严格按名单」仍按配置替换队员。众志攻坚和活动刷关使用相同的补位规则。
- 主线和日常共用同一个澄明度恢复动作，按各自任务核算用量。

本版的跑商、主线地图和编队修复已通过离线回归及模拟画面回放。实际游戏中的特殊主线节点仍需测试反馈。
