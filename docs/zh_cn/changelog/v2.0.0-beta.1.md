## v2.0.0-beta.1 测试版

### PC 前台手动跑商

- Windows x64 安装包新增国服 PC 客户端（前台）控制器，同一包内也可选择安卓模拟器（ADB）。
- 使用 PC 端时，先登录游戏并进入主界面，将游戏窗口设为 16:9，推荐 1280×720 或 1920×1080。窗口需保持可见，助手运行时会使用鼠标。
- 选择「PC 手动跑商（一轮）」预设，核对两座城市后开始。预设执行一次往返，两程均使用 0 本进货书，默认关闭自动使用消耗品。PC 端目前开放手动双城跑商。
- 预设会核对当前 UID 并使用本地账号资料，缺失时采用默认配置。PC 端的完整资料扫描仍待实机验证。

### 跑商修复

- 修复关闭「自动使用撞击钻头」后仍会点击「撞击脱离」的问题。关闭时会等待「护卫队迎击」开放，超时后提示手动处理。开启时兼容按钮文字中「脱／脫」「离／離」的 OCR 识别差异。
